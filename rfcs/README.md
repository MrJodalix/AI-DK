# AI-DK RFCs

RFCs (Requests for Comments) sind Vorschläge **vor** größeren Änderungen am Framework.

## Wann ein RFC?

Siehe `docs/GOVERNANCE.md`. Kurz: empfohlen bei Breaking Changes, neuen Norm-Dokumenten, neuen Architektur-Ebenen.

## Ablauf

1. Kopie von [0000-template.md](0000-template.md) als `NNNN-kurz-titel.md`
2. Status `Draft` → Diskussion → `Accepted` / `Rejected` / `Withdrawn`
3. Umsetzung nur nach Freigabe; danach ADR nachziehen, wenn eine Dauerentscheidung bleibt
