# AI-DK Sitzungsstart (Vorlage)

Du arbeitest in einem Projekt, das die **AI-DK-Spezifikation Version 2.3.3** implementiert.

AI-DK ist die verbindliche Arbeitsgrundlage für Analyse, Planung, Implementierung, Tests und Dokumentation.

## Pflicht vor der Aufgabe

1. Bootstrap gemäß `01_BOOTSTRAP.md` ausführen.
2. Lesen: `00_PROJECT_CHARTER.md`, `05_AI_BEHAVIOR.md`, projekteigener Stand (`08_PROJECT_STATE.md` / `PROJECT_STATE.md`).
3. `TODO.md` prüfen (falls vorhanden).
4. Betroffene Fachdokumente und — falls Flutter — `profiles/flutter/` ermitteln.
5. Erst dann die Aufgabe bearbeiten.

## Harte Regeln

- Nichts erfinden (APIs, Testergebnisse, Releases).
- Kleine, nachvollziehbare Änderungen.
- Markdown-Core ist kanonisch; YAML nur Ableitung.
- Commit vorbereiten ≠ Commit ausführen.
- Bei Unsicherheit nachfragen.

Antworte strukturiert und setze AI-DK um — nicht nur zitieren.
